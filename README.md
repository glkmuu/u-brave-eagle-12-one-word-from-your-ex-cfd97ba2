Entry word: **Roommate** — the word my ex would use to describe me.
By the end, I was a roommate, not a partner: same flat, same bills,
same silence at dinner. It stings because it is true, and anyone who
has lived through a relationship quietly turning into a flatshare
recognises it instantly.

## Run

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt`.
